## Project overview

Document/content project — patient health education materials (肿瘤患者健康教育) from 西南医科大学附属医院 (The Affiliated Hospital of Southwest Medical University). The primary content file is `原始信息.txt`.

Topics covered:
- 肿瘤患者饮食指导 (diet guidance for cancer patients)
- 营养问答 (nutrition FAQ)
- 化疗健康宣教 (chemotherapy health education)

## Content format

`原始信息.txt` uses Markdown-style headings (`#`, `##`, `###`) with numbered lists and bold formatting. The file is UTF-8 encoded Chinese text.
